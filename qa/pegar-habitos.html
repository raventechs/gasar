Traductor de Hábitos — pasos para dejarla lista

Hacelos en este orden. El paso 1 es el más urgente: la clave de Groq estuvo escrita en el código, que es público.

1) Clave de Groq: crear una nueva y borrar la vieja

Abrir las claves de Groq

a) Tocá Create API Key, ponele de nombre RavenTechs-IA y copiá la clave (empieza con gsk_). Guardala en un lugar seguro: solo se ve una vez.
b) En la lista, borrá (Delete) las claves viejas. La de Traductor de Hábitos empezaba con gsk_xF7l. Si CharlAR usaba otra, borrala también.

2) Crear el Worker de IA en Cloudflare

Abrir Cloudflare Workers

a) Create → Create Worker → nombre raventechs-ia → Deploy.
b) Tocá Edit code, borrá todo lo que hay, pegá el código copiado y tocá Deploy.
c) Volvé al Worker → Settings → Variables and Secrets → Add: tipo Secret, nombre GROQ_KEY (en mayúsculas), valor: la clave NUEVA del paso 1 → Deploy.
d) Copiá la dirección del Worker (algo como https://raventechs-ia.TUNOMBRE.workers.dev) y mandámela por el chat: yo la cargo en Traductor de Hábitos y en CharlAR.

3) Dominio habitos.raventechsapp.com

a) Donde administrás raventechsapp.com (el mismo lugar donde cargaste los demás), creá un registro CNAME: nombre habitos, destino raventechs.github.io.
b) En GitHub abrí el repo raventechs-traductor-habitos → Settings → Pages: Source Deploy from a branch, rama main, carpeta / (root). El dominio habitos.raventechsapp.com ya aparece por el archivo CNAME. Cuando termine de verificar, marcá Enforce HTTPS.

Abrir Pages del repo

4) Firebase (proyecto traductor-habitos)

a) Abrir Authentication → Settings

En Authorized domains tocá Add domain y agregá habitos.raventechsapp.com. Revisá en Sign-in method que Google esté activado.

b) Abrir las reglas de Firestore

d) En Firebase tocá dentro del cuadro de reglas, Ctrl+A (seleccionar todo), pegar y botón azul Publicar. Estas reglas no borran ni modifican datos: solo controlan quién puede leer y escribir.

5) Probarla en tu celular

Abrí https://habitos.raventechsapp.com en Chrome → Continuar con Google → Perfil → Cargar datos de práctica → Descubrir → Analizar ahora. Avisame qué ves y la marco como probada.
